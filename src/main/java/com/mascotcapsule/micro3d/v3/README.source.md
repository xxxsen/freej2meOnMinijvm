# MascotCapsule source provenance

The classes in this package were reconstructed with CFR 0.152 from the
`src/main/resource/lib/freej2me.jar` shipped by the upstream
`digitalgust/freej2meOnMinijvm` commit
`c6af07fffde51fe1b1959f584376dec8d912d456`. The source artifact has SHA-256
`39d0943e3ddcacaa0a0b5485a94aee95977590a16acc350fb5d7d2e99b77c725`.

The reconstruction makes the implementation reproducible and reviewable instead
of silently depending on those class files. The code is part of the FreeJ2ME
compatibility layer and is distributed under the same GPL-3.0-or-later terms.
Browser integration changes add API-compatibility shims, deterministic backend
selection and WebGL2 validation diagnostics.
